**Bloom** is a multi-agent post-discharge care companion solving post-treatment care guidance. Families photograph the hospital discharge summary; a Gemini multimodal parser extracts medications, warning signs, and follow-up dates. Specialist agents — orchestrated with **Mastra** — explain the report in the family's language (English/Kannada/Tamil/Hindi), manage medication schedules, track follow-up appointments with overdue detection, and answer midnight symptom worries grounded strictly in the doctor's instructions. **Qdrant** stores embedded discharge-note chunks so every answer is retrieval-grounded; **Enkrypt** guardrails gate triage responses against unsafe medical advice. One photograph replaces four failures: unread reports, missed doses, skipped follow-ups, panicked guesswork — reducing medication errors and avoidable readmissions.
